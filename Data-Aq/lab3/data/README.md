# Andmehõive Labor 3 — katseandmed

Siin on **ainult päistega CSV mallid**, mitte katsetulemused:

- [`drops.csv`](drops.csv) — iga tilga ID, plaadi asukoht, otsik, rõhk, impulss, mõõtkava, pindala ja ruumala ning seos päris rõhukõvera failiga.
- [`placement.csv`](placement.csv) — ekraanimudelile asetatud klaasi all olev laigu pindala, nihe x/y ning serva puudutamise info.
- [`../docs/latency.csv`](../docs/latency.csv) — IRQ/polling reageerimisaja katsed; ainult siis, kui reaalne ostsilloskoobi mõõtmine olemas.

Õppejõu nõue: vähemalt 5 impulsi pikkust, **10 tilka iga pikkuse kohta**; lisaks teine otsik või rõhk 3 pikkusega. Ülesanne nõuab ka iga tilga päris 100 Hz rõhukõverat ning pildilt mõõdetud pindalat ja vastava plaadi vahetüki kõrgust.

Kuni päris andmeid pole, **ära lisa täidetud näidisridu** ega märgi vaatlusandmeid kinnitatuks.
